# Complete textbook license texts

These complete license texts are copied into each packaged textbook's `LICENSE.txt`.
They describe the third-party textbooks, independently of the application code.

`sources.json` records the retrieved source URL and the SHA-256 of each normalized
UTF-8 file. The CC text comes from Creative Commons' legal-code endpoint. The GFDL
texts come from the SPDX license-list-data repository, which reproduces the full
GNU license texts. The reviewed books also retain their original copyright pages
and, where provided, their complete license appendices inside the unchanged PDFs.

The `-or-later` permission comes from each book's copyright notice. A generic
license file alone does not establish that a particular book uses that license.

The packager works offline and rejects missing or changed license-source files.
