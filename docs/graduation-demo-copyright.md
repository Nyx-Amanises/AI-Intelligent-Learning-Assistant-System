# 毕设教材目录与展示的著作权边界

核对日期：2026-11-07。本文记录产品设计依据和一般性法律信息，不是针对具体项目的法律意见，也不认定某次使用已获得授权或必然免责。

“只做毕设、不收费、不公开”会影响使用场景，但本身不是一项概括授权。合理使用是满足法定条件时不需许可的例外；授权则来自权利人、合法许可或其他明确权利依据。二者不能混为一谈。

## 已核对的官方条文

1. [《中华人民共和国著作权法》，中国政府网，2020年修正文本](https://www.gov.cn/guoqing/2021-10/29/content_5647633.htm)。[国家版权局同版原文](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)。
   - 第24条总条件：应当指明作者和作品名称，并且“不得影响该作品的正常使用，也不得不合理地损害著作权人的合法权益”。
   - 第24条第1项：“为个人学习、研究或者欣赏，使用他人已经发表的作品”。
   - 第24条第2项：为介绍、评论作品或者说明问题，在作品中“适当引用”已经发表的作品。
   - 第24条第6项：为学校课堂教学或者科学研究，“翻译、改编、汇编、播放或者少量复制已经发表的作品，供教学或者科研人员使用，但不得出版发行”。
   - 第10条第5项的复制权包括“翻拍、数字化等方式将作品制作一份或者多份”；第12项规定向公众提供、使公众能在自选时间和地点获得作品的信息网络传播权。因此不公开传播，并不当然排除复制权问题。
   - 第3条规定独创性表达的保护，第15条也保护具有独创性选择或编排的汇编作品。事实性书目数据与作品表达、他人有独创性的完整目录编排应区别对待。
2. [《信息网络传播权保护条例》，中国政府网，2013年修订后重新公布全文](https://www.gov.cn/zhengce/2013-02/08/content_2602617.htm)。[中央网信办同版原文](https://www.cac.gov.cn/2013-02/08/c_126468776.htm)。
   - 第2条：除法定例外，将他人作品通过信息网络向公众提供，应取得许可并支付报酬。
   - 第6条第3项：课堂教学或科研例外限于“向少数教学、科研人员提供少量已经发表的作品”。
   - 第8条针对实施九年制义务教育或国家教育规划的远程教育课件，只涉及作品片段、短小作品或单幅作品，且“应当向著作权人支付报酬”。它不是任何教育项目都能免费建全文库的依据。
   - 第10条要求署名、按规定付酬等；其中第4项针对第7、8、9条的服务还要求技术措施限制访问对象。这里不能把所有教育用途概括成免费、无限量开放。

## 按实际使用方式区分

| 使用方式 | 需要区分的边界 |
| --- | --- |
| 合法取得的材料，仅本人在本机学习研究 | 第24条第1项可能适用，但仍受总条件约束。不能仅因本地使用就断言全部合法，也不能把所有个人学习使用一概判为侵权。材料取得方式、复制必要性和对正常利用的影响需要结合事实判断。 |
| 仅向导师、答辩评委展示功能 | 少量必要引用、署名、限制对象、不提供可带走的整本副本，更有合理使用的论证空间。答辩名称或评委人数本身不构成自动免责；展示后分发全文库是另一种使用。 |
| 批量复制1000本完整教材，提供全文阅读、搜索或导出 | 条文没有统一的“多少本、多少页必然合法”数字。整本、批量、替代正常购买阅读等因素使其不能仅凭“毕设”“少量复制”标签推定免责。已有合法授权或开放许可的书应按其许可分别处理。 |
| 将教材或片段发送给云端AI | 不应直接认定每次私有API调用都等于向公众传播，但它也不同于纯本地阅读。需要区分发送整本还是必要片段、平台是否留存或另行训练、是否生成或共享可替代原书的副本，以及材料许可和服务条款。关闭训练选项不等于获得作品授权。 |
| 发布GitHub、部署可访问网站 | 仅公开自有代码或事实书目，与同时提交PDF、正文切片、可恢复的全文数据不同。只要公众能获得教材内容，即便免费，也不能仅依靠“个人学习”解释该传播行为。登录限制不是自动授权。 |
| 录屏并公开演示视频 | 录制界面操作、书目和必要的少量引用，与录入可连续阅读的整章、整本内容不同。原本封闭的答辩录屏公开后，接收对象和传播范围会变化，应重新检查所展示的内容。 |

## 书目、链接、封面与全文分别处理

- 书名、作者、出版社、ISBN、出版年份等通常是事实性元信息；可根据可靠公开来源核对并自行组织，不虚构字段。出版社简介、长篇内容提要、书中图表、正文和有独创性的目录编排不能直接等同于事实数据。
- 通往出版社、作者或学校正式页面的普通链接，与复制其文件并在本站重新提供不同。官网可公开阅读，不表示已经许可本站镜像、再分发或输入任意外部服务；也不应绕过登录、付费或技术限制。
- 封面的插画、摄影、设计可能另有著作权。确认封面来自官网、书名ISBN匹配，只能证明来源与版本，不能单独证明获得重新展示许可。普通页面链接、远程图片嵌入和本地镜像的法律评价也不宜混同；优先使用明确允许展示的封面，或自制文字封面。
- 1000条真实教材书目不等于1000本可阅读全文。若采用书目目录，应在界面明确标注“书目信息／前往官方页面”，不标成“整本可下载”或“已获全文授权”。全文演示样本可选明确开放许可、已获相应许可或自编的材料，并保留其许可条件和来源。

是否适用具体例外，最终取决于实际材料与使用方式；学校的毕设展示要求也不能替代著作权人的授权范围。
