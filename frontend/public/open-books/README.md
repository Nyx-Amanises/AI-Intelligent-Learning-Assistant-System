# 完整开放教材

本目录的 PDF 为真实完整文件，来源、版本、作者、许可及核验哈希记录在 `db/catalog/github-open-books.json`。每本教材的 `ATTRIBUTION.md` 包含具体署名与许可依据。

- `book.pdf`：未经修改的完整原书，保留原有页次、署名和许可声明（如有）。
- `cover.webp`：原 PDF 首页的缩略图。
- `body.txt`：从所有书页提取的全文，供数据库种子及私有学习导入使用；公式、图形、排版以 PDF 为准。
- `ATTRIBUTION.md`：作者、发布方、来源、正文许可和转换说明。

这些第三方教材不适用本应用代码的许可证。请按各自许可保留署名、非商业使用或相同方式共享等条件。GitHub 上能够公开下载本身不等于授权；此目录只包含单独核验了正文许可的样本。
