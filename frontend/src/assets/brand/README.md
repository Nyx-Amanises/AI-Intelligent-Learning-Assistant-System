# 知序标志

以中式印章与刻字为参考：朱砂色的「知」字印记，配墨绿色的「知序」字标和拼音落款。字形、印框和拼音均由 SVG 路径绘制，无字体或外部图片依赖。

- `zhixu-logo.svg`：184 × 64 的横版组合，供登录页与展开的侧栏使用。
- `zhixu-mark.svg`：64 × 64 的独立印记，供折叠侧栏使用。
- `public/favicon.svg`：小尺寸版本，省略细印框并加粗笔画，供浏览器标签使用。

配色：墨绿 `#294D40`、朱砂 `#A64B38`、印白 `#FFFDF7`。所有资源均为透明背景。

界面通过 `BrandLogo.vue` 共用标志，保留「知序」作为无障碍名称。修改资源时需检查 44px 印记，以及 168px、172px 和 184px 的横版显示效果。
